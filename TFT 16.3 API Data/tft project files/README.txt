TFT Set 16.2 snapshot dataset (CommunityDragon)
Retrieved: 2026-01-21T20:01:44.882038+00:00

Files:
- champions.csv: shop units (cost 1-5, apiName TFT16_*) with ability text and base stats
- champion_traits.csv: champion->trait edges
- ability_variables.csv: per-champion spell variables split by star level
- traits.csv + trait_effects.csv: trait text and breakpoint variables
- items.csv + item_components.csv: all set items resolved, includes components, completed items, artifacts, emblems, consumables
- augments.csv: all set augments resolved (name/desc/effects)
- *.jsonl: raw records for flexible parsing
- metadata.json: provenance + counts + notes
