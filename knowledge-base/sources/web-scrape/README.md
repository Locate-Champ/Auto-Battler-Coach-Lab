# Web Scrape Source

This folder stores markdown files produced by crawl4ai web scraping.

## Expected upload format

- Markdown files (`.md`) only.
- Keep original filenames if possible for easy traceability.

## Upload location

Place new files in `incoming/`.

## Assets (future)

If the scrape later includes assets (images, PDFs, etc.), place them in a sibling folder under `web-scrape/` and reference them in the manifest. No asset folder is required yet.
