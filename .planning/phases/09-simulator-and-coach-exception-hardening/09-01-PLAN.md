Exception type rationale:
- `OSError`: file not found, permission denied, disk I/O error
- `ValueError`: corrupt or incompatible pickle protocol
- `pickle.UnpicklingError`: malformed pickle data (subclass of Exception, not ValueError — must be explicit)
- EOFError excluded: joblib wraps truncated-file errors as pickle errors internally

Exception type rationale:
