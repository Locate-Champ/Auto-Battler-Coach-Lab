1. Add three methods to the DataLoader class in models/data_loader.py, placed immediately after the existing `close()` method (after line 119):

```python
def __enter__(self) -> "DataLoader":
    return self

def __exit__(self, exc_type, exc_val, exc_tb) -> bool:
    try:
        self.close()
    except Exception as cleanup_err:
        _log.warning(
            "DataLoader worker pool cleanup failed during __exit__: %s. "
            "Original exception (if any) takes priority.",
            cleanup_err,
        )
    return False  # Never suppress the original exception

def __del__(self) -> None:
    if getattr(self, "_pool", None) is not None:
        import warnings

        warnings.warn(
            "DataLoader was garbage-collected without being closed. "
            "Use 'with DataLoader(...) as dl:' or call dl.close() explicitly.",
            ResourceWarning,
            stacklevel=2,
        )
        try:
            self.close()
        except Exception:
            pass
```

Key implementation notes:
- `__enter__` returns self per user decision (backward compatible, standalone usage still works)
- `__exit__` wraps `self.close()` in try/except per user decision: log WARNING on cleanup failure, return False to never suppress the original exception
- `__del__` uses `getattr(self, "_pool", None)` not `self._pool` to handle partially-initialized instances gracefully
- `__del__` imports `warnings` locally (module may be partially torn down during interpreter shutdown)
- `__del__` wraps `self.close()` in bare `except Exception: pass` since exceptions in `__del__` are unreliable
