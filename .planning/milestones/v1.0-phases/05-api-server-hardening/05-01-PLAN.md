<objective>
Migrate the FastAPI server from the deprecated @app.on_event("startup") pattern to the modern @asynccontextmanager lifespan pattern, enforce a hard startup failure gate (sys.exit(1) if any model fails to load), replace all module-level globals with app.state attributes accessed via Depends() dependency injection, add a global exception handler for structured JSON error responses, and create a comprehensive test suite.

Purpose: Eliminates stale-state bugs on uvicorn --reload, prevents endpoints from ever serving None models, and makes each endpoint's dependencies explicit and testable via dependency_overrides.

Output: Migrated server.py, new deps.py, updated requirements.txt, new test_api_server.py
</objective>

**Create `app/api/deps.py`** with two flat dependency functions per user decision:

```python
from fastapi import Request
from src.models import PlacementModel, TFTRecommender

def get_recommender(request: Request) -> TFTRecommender:
    """Return the recommender from app.state. Trusts lifespan guarantee."""
    return request.app.state.recommender

def get_placement_model(request: Request) -> PlacementModel:
    """Return the placement model from app.state. Trusts lifespan guarantee."""
    return request.app.state.placement_model
```

No None-checks, no validation -- trusts the lifespan guarantee per user decision. One function per resource, flat (not a class).

**Rewrite `app/api/server.py`:**

1. **Remove** the two module-level globals (`recommender = None`, `placement_model = None`).

2. **Remove** the entire `@app.on_event("startup")` handler and `startup()` function.

3. **Add** an `@asynccontextmanager` lifespan function that:
   - Logs INFO "Loading Auto-Battler Coach models..."
   - Wraps TFTRecommender instantiation in try/except Exception: log CRITICAL with exc_info=True, then sys.exit(1)
   - Wraps PlacementModel instantiation + prepare_data + train in try/except Exception: log CRITICAL with exc_info=True, then sys.exit(1)
   - Assigns both to app.state (app.state.recommender, app.state.placement_model)
   - Logs INFO "All models loaded, server ready"
   - yield
   - After yield: del app.state.recommender, del app.state.placement_model
   - Logs INFO "Server shutdown complete, resources released"

4. **Change** the app creation to pass lifespan: `FastAPI(title="Auto-Battler Coach API", version="1.0.0", lifespan=lifespan)`

5. **Add** a global exception handler registered on the app:
   ```python
   @app.exception_handler(Exception)
   async def global_exception_handler(request: Request, exc: Exception):
       _log.exception("Unhandled error in %s %s", request.method, request.url.path)
       return JSONResponse(
           status_code=500,
           content={"error": "internal_error", "detail": "An internal error occurred", "status": 500},
       )
   ```

6. **Migrate all 7 endpoints** that use `recommender` or `placement_model`:
   - Remove all `if not recommender: raise HTTPException(503)` None-checks
   - Add `Annotated[TFTRecommender, Depends(get_recommender)]` or `Annotated[PlacementModel, Depends(get_placement_model)]` parameters
   - Import `get_recommender`, `get_placement_model` from `app.api.deps`
   - Import `Annotated` from typing, `Depends` from fastapi
   - Endpoints that need recommender: get_stats, get_stage_comps, get_augments, get_augment_fit, get_recommendations, analyze_board, get_priority_units
   - Endpoints that DON'T need model deps (leave unchanged): root, get_meta_comps, get_early_comps, get_item_suggestions, update_lobby

7. **Keep** all Pydantic models (Unit, BoardState, CompCount, AugmentFitRequest) in server.py -- same location, no move.

8. **Keep** CORS middleware config unchanged.

9. **Keep** the `main()` function and `if __name__` block unchanged.

10. **Replace** `print()` calls with `_log` (logging.getLogger(__name__)) -- use `_log.info()` consistent with Phase 2 patterns.

11. **Keep** `sys.path.insert(0, ...)` import hack unchanged -- removing it is not in scope and could break imports.

12. **Add** `from fastapi.responses import JSONResponse` import for the exception handler.

**Do NOT:**
- Move Pydantic models to a separate file (not in scope)
- Add a readiness probe endpoint (user explicitly decided against it)
- Add None-checks in deps.py (user explicitly decided against it)
- Change any endpoint URL, request shape, or response shape
