```python
def _round_num_from_stage(stage: str) -> int:
    stage_num = int(stage.split("-")[0])
    round_in_stage = int(stage.split("-")[1])
    if stage_num <= 1:
        return max(0, round_in_stage - 1)
    base = 4 + (stage_num - 2) * 7 + (round_in_stage - 1)
    if stage_num >= 3:
        base -= 1
    return max(0, int(base))
```

**1. Add a module-level `_gamestate_to_row(state: GameState) -> dict[str, Any]` helper** that converts GameState into the dict format TFTFeatureEngineer.transform() expects. The row must include:
- `"level"`: `state.player.level`
- `"hp"`: `state.player.hp`
- `"gold"`: `state.player.gold`
- `"round"`: computed from `state.stage` using the same logic as `coach.coach._round_num_from_stage()` -- replicate the logic inline (do NOT import from coach.coach to avoid circular dependency). The formula: `stage_num <= 1 -> max(0, round_in_stage - 1)`, else `base = 4 + (stage_num - 2) * 7 + (round_in_stage - 1)`, subtract 1 if `stage_num >= 3`, clamp to `max(0, base)`.
- `"streak"`: `state.player.streak` (signed win - loss)
- `"augments"`: `list(state.augments)`
- `"units"`: list of dicts, each with `"champion_id"`, `"star_level"`, `"items"` (as list), `"position"` -- built from `state.board`
- `"traits"`: `dict(state.traits)` if state.traits else `{}` (the `{trait_name: count}` dict format)

**2. Add a module-level `_placement_to_score(placement: float) -> float` helper:**
- Linear inversion: `max(0.0, min(1.0, (8.0 - placement) / 7.0))`
- Placement 1 -> score 1.0, placement 8 -> score 0.0

**3. Rewrite `SklearnEvaluator.score()`:**
- Lazily initialize a `TFTFeatureEngineer` instance on first call, cached via `object.__setattr__(self, '_feature_engineer', fe)` (same frozen-dataclass pattern as `_model`). Add `_feature_engineer: Optional[object] = None` to the dataclass fields (with `field(default=None, repr=False)`).
- Import `TFTFeatureEngineer` locally inside score() to avoid import-time cost for users who don't use sklearn evaluator.
- After initializing the feature engineer, validate `len(fe.feature_names()) > 0`. If zero, raise `RuntimeError("TFTFeatureEngineer produced no features -- combat_data.json may be missing")`.
- Call `_gamestate_to_row(state)` to get the row dict.
- Wrap `fe.transform(row)` in try/except. On any exception, raise `ValueError(f"Feature extraction failed: {e}. GameState stage={state.stage}, board_size={len(state.board)}")` from the original exception. This satisfies the locked decision: feature extraction failure raises ValueError with details.
- Get the feature vector (numpy array) from transform().
- Reshape to 2D if needed: `features.reshape(1, -1)`.
- Call model prediction: check `hasattr(model, 'predict_proba')`. If yes (classification model), use `model.predict_proba(features)` and extract `proba[:, 0]` (probability of placement 1, i.e. best placement class). BUT since XGBoost classifiers for placement may have 8 classes, a simpler approach: use `model.predict(features)[0]` to get the predicted placement as a float, then apply `_placement_to_score()`. If the model has `predict_proba`, also try `predict_proba` and compute expected placement as `sum(i * p for i, p in enumerate(probs, 1))`, then use `_placement_to_score()`. Actually, the simplest robust approach: always use `model.predict(features)[0]` which returns a float (works for both regressor and classifier), and apply `_placement_to_score()`. This avoids the predict_proba complexity entirely. For the predict() call, let exceptions propagate (Claude's discretion per CONTEXT.md).
- Return the score (a float in [0, 1]).

**4. Update `_load()` to raise RuntimeError** on failure. The current code already does this via the `except (ImportError, OSError)` -> `raise RuntimeError(...)`. Keep that. But also wrap `joblib.load()` in a try/except for other load errors (e.g. corrupt file): catch `Exception` (just this one spot) and re-raise as `RuntimeError(f"Failed to load sklearn model from {self.model_path}: {e}")`. This ensures the locked decision "Model load failure raises RuntimeError immediately" is fully honored.

**5. Rewrite `default_evaluator()` with the new priority chain:**
- First: try SklearnEvaluator from `runtime_outputs_dir() / "evaluator_sklearn.joblib"`. If path exists, construct `SklearnEvaluator(model_path=str(path))`, call `_load()` to validate. On success, log `_log.info("Evaluator selected: SklearnEvaluator from %s", path)` and return. On any exception from `_load()`, log `_log.warning("SklearnEvaluator failed to load from %s, trying next", path, exc_info=True)` and fall through.
- Second: try LinearEvaluator (existing logic). Add `_log.info("Evaluator selected: LinearEvaluator from %s", path)` on success.
- Third: fallback to HeuristicEvaluator. Add `_log.info("Evaluator selected: HeuristicEvaluator (no trained model found)")`.
